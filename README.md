# Resume Screening AI

A Machine Learning based Resume Screening Application built using Python, Streamlit, Scikit-learn, TF-IDF, and Logistic Regression.

## Features
- Upload Resume PDF
- Extract Text using PyPDF2
- Convert Resume into Numerical Features using TF-IDF
- Predict Selected/Rejected using Logistic Regression
- Interactive Streamlit Web App

## Technologies Used
- Python
- Streamlit
- Scikit-learn
- Pandas
- PyPDF2
- NLP
- TF-IDF
- Logistic Regression

## How to Run

Install libraries:

pip install -r requirements.txt

Run application:

streamlit run app.py

## Project Workflow

Resume PDF
↓
Text Extraction
↓
TF-IDF Vectorization
↓
Machine Learning Prediction
↓
Selected / Rejected
